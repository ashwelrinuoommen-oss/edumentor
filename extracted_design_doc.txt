1. Design Direction
EduMentor should adopt the supplied reference’s premium dark-tech aesthetic while shifting the visual language from generic machine-learning marketing toward focused learning, active recall, and measurable mastery.
Core design principleKeep the interface calm and spacious, then use restrained cyan/violet gradients and subtle motion to make learning progress feel intelligent rather than gamified.
Reference traits to retain
Dark, high-contrast canvas with a centered content column.
Compact floating navigation bar with rounded corners.
Small announcement / status pill above the hero headline.
Large two-line headline with generous whitespace.
Short supporting paragraph and two clear CTAs.
Abstract flowing gradient artwork anchoring the bottom of the hero.
Soft borders, rounded corners, restrained glow, and premium SaaS styling.
Changes for EduMentor
Replace the abstract AI-company message with a learning outcome: turn notes into a structured path and prove understanding.
Make Concept → Recall → Mastery the primary product narrative.
Use learning-state visuals—cards, progress rings, recall prompts, confidence indicators—rather than corporate technology imagery.
Prioritize clarity and trust: explain what happens to student notes and how mastery is measured.

4. Hero Section Specification
The hero is the strongest direct adaptation of the reference screenshot. It should use the same centered, minimal composition but communicate EduMentor’s learning loop.
Proposed hero copy
EyebrowAI-Powered Adaptive Learning
HeadlineTurn Your Notes Into a Path From Concept to Recall to Mastery
Supporting textEduMentor transforms your own study material into structured concepts, tests real understanding through active recall, and brings back what you need to master next.
CTA hierarchy
Primary: Start Learning Free — filled gradient button.
Secondary: See How It Works — transparent / outlined button.
Keep both CTAs visually compact; do not let buttons overpower the headline.
5. Hero Artwork & Motion
Instead of copying the reference artwork, use an original flowing visualization representing knowledge moving through the three states: Concept, Recall, and Mastery.
Three luminous ribbons travel from left to right and converge toward a subtle mastery node.
Use cyan as the primary learning path and violet as a secondary highlight.
Very slow horizontal drift creates life without distracting from the hero copy.
Add faint particles or dots only around the path; avoid busy starfields.
On hover over Concept / Recall / Mastery, the corresponding ribbon can brighten and reveal a one-line explanation.
Respect prefers-reduced-motion and provide a static fallback.

7. Responsive Design
Desktop ≥ 1200 px: centered max-width around 1120–1200 px; generous hero spacing.
Tablet 768–1199 px: reduce hero type and artwork scale; keep two-column product previews where comfortable.
Mobile < 768 px: collapse navigation into menu, stack CTAs, reduce decorative artwork height, and keep key message above the fold.
Touch targets should be at least 44 × 44 px.
Do not hide essential learning progress or recall controls on small screens.
8. Interaction & Animation Guidelines
Page entrance: 250–450 ms fade/translate for major groups, staggered lightly.
Navbar: subtle blur and border transition on scroll.
CTA hover: 150–220 ms lift plus restrained glow; avoid large scaling.
Cards: 160–220 ms border/translate transition; use motion to clarify state.
Recall reveal: answer content can use a short opacity + vertical transition.
Mastery progress: animate only when progress changes, not continuously.
Decorative hero ribbons: slow ambient movement; never compete with text.
Reduced motion: disable ambient movement and keep functional transitions minimal.
9. Accessibility & Trust
Maintain readable contrast between primary text and dark backgrounds.
Every icon button needs an accessible name.
Never communicate mastery using color alone; pair color with text, icon, or score.
All interactive elements require visible keyboard focus.
Recall questions and answers should be fully usable with keyboard and screen readers.
Explain note privacy clearly near the upload/import flow.
Avoid claiming that AI 'knows' a student’s understanding; phrase results as estimates based on responses.

11. Implementation Notes
Build the visual system with reusable design tokens for spacing, radius, typography, surface, border, and accent gradients.
Use CSS gradients and lightweight SVG/CSS shapes for the hero artwork where possible rather than heavy raster assets.
Keep the page performant: decorative animation should be GPU-friendly and pause when not visible.
Componentize navigation, buttons, concept cards, recall cards, mastery indicators, and adaptive insights.
Use semantic HTML structure: header, nav, main, section, article, footer.
Track meaningful product events such as note import, concept completion, recall response, confidence rating, and mastery progression.
Design Summary
The supplied website is a strong reference for a premium, modern SaaS presentation. EduMentor should borrow its composition—not its branding or artwork: dark cinematic space, centered typography, floating navigation, gradient accents, and restrained motion. The result should feel like an intelligent study product whose interface makes the learning loop visible: understand the Concept, retrieve it through Recall, and demonstrate Mastery.
Primary visual messageLess 'AI technology demo' — more 'calm, intelligent learning system'.
